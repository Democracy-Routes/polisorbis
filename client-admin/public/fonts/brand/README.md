# Self-hosted fonts

Served at `/fonts/brand/` for all three clients, so no request goes to a
font CDN. From the fontsource packages (space-grotesk 5.0.17, fraunces
5.0.18), latin subset, woff2. Both fonts are under the SIL Open Font License
1.1 (see the LICENSE files here).

- Space Grotesk 400 and 600: body text and UI.
- Fraunces 600: the landing page heading.
